# rwl-install-wizard 0.2.59 Reliability Fixes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the wizard's generated overlays install reliably against `runwhen-platform` chart 0.2.59 by fixing 6 semantic findings + a META (PREREQUISITES.md emission, invariant lint, render oracle) — the STOXX POC's overlays must become install-ready by construction.

**Architecture:** Correctness comes from three non-helm layers (the plugin NEVER runs helm at generate time): (1) correct-by-construction emits in `data/knob-catalog.yaml`; (2) static invariant checks in `lib/catalog-lint.sh`; (3) a maintainer render oracle in `tests/test-airgap-registry.sh` that `helm template`s golden fixtures against the chart. The operator additionally receives a copy-paste render-gate *command* in a per-run `PREREQUISITES.md`.

**Tech Stack:** YAML catalog (bash 3.2 line-oriented lint + embedded Ruby for structural checks), Markdown data fragments, a Claude-driven SKILL for interview/generate, bash test harness, `helm template` (maintainer-side only).

## Global Constraints

- **Maintenance contract:** feature edits land in `data/knob-catalog.yaml` + `data/` files. `skills/rwl-install/SKILL.md` is edited ONLY for genuine interview/generate behavior. `lib/` + `tests/` carry the guard/oracle layers.
- **Every edit re-runs `bash rwl-install-wizard/lib/catalog-lint.sh rwl-install-wizard/data/knob-catalog.yaml rwl-install-wizard/data` and it MUST exit 0.**
- **Command-only render gate:** the plugin never invokes `helm` at generate time. Findings [1]/[6] are prevented by emits + lint, never by an at-generate render.
- **No guesses (hard re-prompt):** the interview never finishes an axis with a guessed value. Shape-critical params are `required: true`; the interview re-prompts and never emits a placeholder.
- **helm is always invoked with an explicit argv array** (`helm template … -f a -f b`), never a space-joined string variable (zsh collapses an unquoted `"$VAR"` of `-f a -f b` into ONE argument and silently mis-invokes).
- **bash 3.2 compatible** (macOS default): no `declare -A`, no `${var,,}`, no `|&`.
- **Secret-free:** emits wire secrets by name (`existingSecret`/`*Ref`) only; never an inline secret literal.
- **chartCompat stays `">=0.2.37 <0.3"`** (0.2.59 is within range; do not change it).
- **Chart under test:** `RWL_CHART_PATH=/Users/rohitekbote/emdash/worktrees/rwlight-helm/emdash/for-qna-3tl69/charts/runwhen-platform` (version 0.2.59).
